ValutaScanner privati

Idealista e Immobiliare bloccano la lettura da server: l'estrazione affidabile avviene nel tuo browser, sull'annuncio aperto. Scegli lo strumento per dispositivo:

💻 Computer (anche PC di lavoro) — segnalibro
Zero installazioni. Una volta sola:
1. Rendi visibile la barra dei preferiti (Chrome/Edge: ⌘⇧B o Ctrl⇧B).
2. Trascina questo bottone sulla barra dei preferiti:

🏠 Valuta questa casa

Uso: apri un annuncio → clic sul segnalibro → si apre Valuta Casa precompilato → controlli i campi → Valuta.
📱 iPhone — comando rapido (consigliato)
Una volta sola, 2 minuti. Poi lo usi dal tasto Condividi di Safari.
1. Premi qui: copiato ✓
2. Apri l'app Comandi Rapidi (già sull'iPhone) → tab «Comandi» → + in alto.
3. Tocca «Cerca azioni» → scrivi javascript → scegli «Esegui JavaScript su pagina web Safari».
4. Tocca il riquadro del codice d'esempio → cancellalo → incolla (tieni premuto → Incolla).
5. Tocca la ⓘ in basso → attiva «Mostra nel foglio di condivisione» → Fine.
6. Tocca il nome in alto → rinomina in Valuta Casa → Fine.
Uso: annuncio aperto in Safari → tasto Condividi (quadrato con freccia) → scorri → Valuta Casa. Si apre il sito precompilato: controlli e premi Valuta.
📱 iPhone — alternativa: segnalibro Safari
Se preferisci il segnalibro al comando rapido:
1. copiato ✓
2. Safari, su questa pagina: tasto Condividi → «Aggiungi segnalibro» → nome «Valuta Casa» → Salva.
3. Apri i segnalibri (icona libro) → Modifica (in basso a destra) → tocca «Valuta Casa» → nel campo indirizzo cancella tutto e incolla → Fine.
4. Uso: annuncio aperto → icona libro → tocca «Valuta Casa».
🧩 Chrome desktop — estensione (opzionale)
Stessa estrazione, un click sull'icona invece del segnalibro. Chrome → chrome://extensions → modalità sviluppatore → «Carica non pacchettizzata» → cartella estensione/ del repo. Solo sul PC personale.
Bookmarklet e comando leggono la pagina che TU hai aperto nel TUO browser: nessun blocco aggirato.

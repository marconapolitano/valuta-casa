📱 iPhone — Valuta Casa

Crei un Comando una volta. Poi su un annuncio → Condividi → Valuta Casa → opinione di Claude vs OMI.

1. Copia il codice






2. Crea il Comando (Shortcut)


a) App Comandi → + (nuovo).


b) Tocca la freccetta/Info → attiva Mostra nel Foglio di Condivisione. Tipi accettati: lascia URL (o "Pagine web Safari").


c) Aggiungi azione → cerca Esegui JavaScript sulla pagina web → aggiungila.


d) Tocca il codice di esempio nell'azione, cancellalo, incolla il codice copiato al punto 1.


e) Aggiungi azione → Apri URL. Come URL scegli la variabile Risultato JavaScript (la propone sopra la tastiera).


f) Nome: Valuta Casa. Fine.



3. Usalo


Apri un annuncio in Safari → tasto Condividi → scorri → Valuta Casa. Prima volta: inserisci la password.


Dalle app native (es. app Idealista) scegli prima Apri in Safari, poi Condividi. Lo Shortcut legge la pagina solo in Safari.
